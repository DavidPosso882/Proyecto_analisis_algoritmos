## Spec R4a-exacto — Subestructura y recurrencia (R4-03, 2026-10-27, ANTES de codificar; feature odd/tasks/r4a-exactos.md)

Subestructura óptima: sea el tour óptimo que sale de 0, visita todos y vuelve
a 0. Quito el último tramo (j → 0): lo que queda es un camino óptimo que sale
de 0, visita todos los nodos exactamente una vez y termina en j. Si existiera
un camino 0 ⇝ j más barato visitando los mismos nodos, lo empalmaría con
j → 0 y obtendría un tour mejor — contradicción. El óptimo global se arma con
óptimos de subconjuntos (condición: costos dirigidos c[i][j] fijos ≥ 0).

Recurrencia (Held-Karp): C(S, j) = costo mínimo saliendo de 0, visitando
exactamente los nodos de S y terminando en j (0 ∉ S, j ∈ S).
Base: C({j}, j) = c[0][j].
Paso: C(S, j) = mín { C(S∖{j}, i) + c[i][j] } sobre i ∈ S, i ≠ j.
Tour óptimo = mín { C(V∖{0}, j) + c[j][0] } sobre j ≠ 0, con V los k lugares.
Complejidades con fuente (Bellman, R. (1962), *Dynamic programming treatment
of the travelling salesman problem*, JACM 9(1); Held, M. y Karp, R. M. (1962),
*A dynamic-programming approach to sequencing problems*, J. SIAM 10(1)):
fuerza bruta O(k!) tiempo y O(k) memoria; Held-Karp O(k²·2^k) tiempo y
O(k·2^k) memoria (una entrada por (subconjunto, final)). Tabla estimada:
k·2^k entradas × 8 bytes (R4-05).
